# Student Performance Analysis and Prediction

## Project Overview
This project analyses student performance using Python, Pandas, NumPy, Matplotlib and Seaborn. It also uses a Linear Regression machine learning model to predict students' final scores based on selected academic factors.

## Objectives
- Analyse student academic performance.
- Explore the relationship between study hours, attendance and final scores.
- Visualise patterns using graphs and a correlation heatmap.
- Build a Linear Regression model to predict final scores.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset
The project uses 200 synthetically generated student records.

Features:
- Study_Hours
- Attendance
- Previous_Score
- Assignments
- Final_Score

**Note:** The dataset is synthetic and does not contain actual student records.

## Project Workflow
1. Dataset generation
2. Data inspection
3. Data cleaning
4. Exploratory Data Analysis (EDA)
5. Data visualisation
6. Linear Regression model training
7. Model evaluation
8. New student score prediction

## Model Performance
- Mean Absolute Error (MAE): 4.31
- R² Score: 0.838

These results are based on the synthetic dataset and should not be interpreted as real-world prediction accuracy.

## How to Run
1. Clone or download this repository.
2. Install the required libraries:
   `pip install pandas numpy matplotlib seaborn scikit-learn jupyter`
3. Open `student_analysis.ipynb` in VS Code or Jupyter Notebook.
4. Run the notebook cells in order.
